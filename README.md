# Real-time-game-voice-translation
游戏语音实时翻译
下载方法：
下载所有代码，下载完成后运行run.bat文件
一、日常使用步骤

启动
双击 `run.bat`（唯一入口，不要直接运行 main.py）。
- 首次启动会自动创建虚拟环境并安装依赖（需已安装 Python 3.9+ 并加入 PATH）。
- 启动时会先加载本地 STT 模型（约 10~30 秒），然后才弹出主窗口。这是为了避免 Qt 与识别引擎的加载顺序冲突，属于正常现象。

听入翻译（外国人说话 → 中文字幕）
1. 主界面语言选择「英语」或「俄语」（对方说什么就选什么）。
2. 点击「开始听入」。
3. 软件自动捕获系统声音（游戏内语音、Discord、浏览器等都行），识别并翻译成中文，显示在屏幕上方的字幕悬浮窗。
4. 悬浮窗可拖动，「锁定」后不拦截鼠标，可穿透点击游戏画面。

说出翻译（你说中文 → 外语语音）
1. 选择目标语言（英语/俄语）和语音音色（如 Andrew、Dmitry）。
2. 点击「开始说出」。
3. 对着麦克风说中文，软件自动识别 → 翻译 → 用外语语音播放出来。
   - 停顿约 1 秒即触发翻译，不必按键。
   - 建议戴耳机使用，避免扬声器声音被麦克风再次录进去。

想让外国人在游戏语音里直接听到翻译声（可选，需 VB-Cable）
1. 安装 VB-Cable（免费虚拟音频线）并重启电脑。
2. 系统设置 → 声音 → 把「输出设备」设为 CABLE Input（这样翻译声进入虚拟线）。
   - 注意：此时你自己的音箱/耳机听不到翻译声，可在声音设置里开启「立体声混音」监听，或直接在软件内勾选同时走默认播放设备（视版本而定）。
3. 游戏或 Discord 的「麦克风输入」设为 CABLE Output。
4. 效果：你说中文 → 游戏内外国人听到英语/俄语语音。

常见问题
| 现象 | 原因/处理 |
|---|---|
| 双击后闪退 | 查看 `game_translator/crash_log.txt`；确认 Python 已装且在 PATH |
| 翻译失败 | MyMemory 翻译接口需要联网，检查网络 |
| 识别不出声音 | Windows 声音设置里确认目标程序正在出声；换默认输出设备 |
| TTS 无声 | edge-tts 需联网；确认输出设备正确 |
需要满足的环境
1. **Windows 10/11 64 位**（用到 WASAPI Loopback，Win7 不支持）
2. **Python 3.9 ~ 3.12**，安装时勾选 "Add Python to PATH"
3. **联网**（翻译用 MyMemory 接口、TTS 用微软 edge-tts，均需联网；识别模型已内置不需要下载）

使用流程
1. 解压到任意**纯英文路径**（如 `D:\GameTranslator\`，中文路径可能出问题）
2. 双击 `run.bat`，等待自动装依赖（首次约 3~5 分钟）
3. 之后每次启动直接双击 `run.bat`
游戏实时语音翻译 使用说明

【环境要求】
- Windows 10/11 64位
- 已安装 Python 3.9~3.12（安装时勾选 Add to PATH）
- 需要联网

【启动】
双击 run.bat
首次运行会自动安装依赖（3~5分钟），之后启动约 10~30 秒出界面。

【听外国人说话】
1. 语言选对方说的语言（英语/俄语）
2. 点「开始听入」→ 屏幕上方出现中文字幕悬浮窗
3. 悬浮窗可拖动，点「锁定」后可穿透点击

【你说中文变外语】
1. 选目标语言和音色
2. 点「开始说出」，对麦克风说中文，停顿1秒自动翻译播放
3. 建议戴耳机，避免声音循环

【让对方在游戏语音里听到】（可选）
需另装 VB-Cable 虚拟音频线：
系统输出 → CABLE Input，游戏麦克风 → CABLE Output


架构速查
| 文件 | 职责 |
|---|---|
| launcher.py | 唯一入口：先加载 STT 模型，再 import PyQt5（顺序不能反，否则段错误） |
| main.py | 主窗口 UI、双工作线程调度 |
| audio_manager.py | pyaudiowpatch：系统声音 loopback 捕获 / 麦克风 / 播放 |
| stt_engine.py | faster-whisper 识别，优先从 models/ 本地加载 |
| translator.py | MyMemory API 翻译（Google 被墙的替代） |
| tts_engine.py | edge-tts 合成，支持音色/语速/音调，自动补标点 |
| overlay.py | 置顶字幕悬浮窗（可穿透） |
| config.py | 所有可调参数与音色列表 |
